# 分享与标签验证记录

日期：2026-10-11。使用 Java 8、实际 HTTP 接口及隔离 H2 MySQL 模式数据库，不连接生产服务器。

- 核心测试 169 项、管理测试 209 项、新增分享/标签测试 202 项全部通过，共 580 项。
- 单帐号可授权两个接收人，重复及并发授权不重复创建；按完整用户名查找，不返回全体用户列表。
- 未授权帐号、同平台其他帐号、所有者原接口均不能越权读取；接收人不能修改、删除或再次分享，管理员不能代为分享。
- view/copy 独立验证授权并返回原帐号最新密码；撤销一个接收人不影响另一个；删除原帐号级联清除授权。
- 停用接收人后旧会话失效；停用所有者暂停分享，恢复后授权仍在。
- 标签同用户复用、不同用户隔离，非法颜色、超长名称、跨用户标签、超过 20 个均被拒绝；无效标签回滚整个帐号保存。
- 省略 tag_ids 保留原绑定，空数组移除；本人和收到的列表支持标签与搜索取交集；分享详情可看到最新标签。
- 分享授权、撤销、接收人显示/复制密码记录审计；模拟审计表不可用时，不授予新权限、不提交撤销、不返回密码。日志不含密码。
- 测试中的审计故障注入会产生预期的 SQL 异常类型输出，并非真实数据库错误。

Windows 联调详见 [客户端验证记录](../desktop/验证记录.md)。H2 测试不能证明 MySQL 5.5 的 DDL、排序规则和实际持久化已经通过；服务器尚需按 [升级说明](SHARING-UPGRADE.md) 应用 004 并验收。
