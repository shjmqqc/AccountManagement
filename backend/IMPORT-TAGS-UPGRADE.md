# Excel 导入与标签管理升级（Windows 1.1.8）

先更新后端，再更新 Windows。H5 无需更新；已有 H5 能显示更新后的标签。

数据库结构需已执行至 `006-mobile-search.sql`。本次不新增 SQL、不重建表、不更换配置或加密密钥。未完成 006 的服务器先按 [006 升级说明](MOBILE-SEARCH-UPGRADE.md) 完成迁移。

1. 备份当前数据库、后端 JAR、配置和原加密密钥。
2. 仅停止帐号管理后端，用本次 `account-management-core.zip` 中的 `account-management.jar` 替换旧 JAR；依赖、配置、端口和密钥保持原样，按原方式启动。
3. 安装 Windows 1.1.8，或上传 `AccountManagement-update-server-1.1.8.zip` 内文件至原更新目录；先上传 nupkg，最后上传 `releases.win.json` 和 `.sig`，客户端检查更新。
4. 主窗口点“Excel 导入”，下载模板、填写、选择文件预览后确认。测试重复导入，确认原密码未覆盖，并检查逐行结果。
5. 标签筛选旁点“管理标签”：测试改名/改色后多个关联帐号同步、重名拒绝、删除后帐号与分享授权保留。

导入仅支持 `.xlsx`，读取第一个工作表，首行必须为模板七列：平台名称、平台地址、帐号名称、登录帐号、密码、备注、标签。最多 1000 数据行、10 MB；拒绝公式及 Excel 错误单元格，校验失败行不提交。帐号和密码按文本填写，避免 Excel 提前丢失前导零或长数字精度。

重复判定沿用数据库规则：同用户的同平台、同登录帐号、同帐号名称。文件内重复按行处理，第一条成功后，后续重复行跳过；此前已存在的记录直接跳过，密码、备注、标签均不修改。

已有平台保留原地址；新平台取第一条成功记录的地址。标签按名称复用，保留原色；新标签为蓝色，多标签以分号分隔。单行的平台、标签及帐号在同一事务中提交或回滚。导入不会自动分享。

会话失效、网络中断、服务器故障或不支持的旧后端会停止后续行；网络异常行标为“结果待确认”，应先核对帐号库。重新选择同一文件可再次导入，已经成功的记录会跳过。停止操作等待当前行返回后生效，不承诺撤回已经提交的行。

标签仅允许所有者修改/删除，删除确认显示最新读取的使用数；删除只解除标签关联，不删除帐号或分享。Windows 中重复名称拒绝保存，不做自动合并。

本地测试基于 Java 8/H2 和 Windows 客户端，实际 MySQL 5.5、生产数据与 Windows 10 仍需部署后验收。回退程序前保留本次备份；没有新增表结构，但旧 Windows 不提供这些入口。
