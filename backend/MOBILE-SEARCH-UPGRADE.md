# H5 查找与分享改版升级

本次需同时更新数据库、后端和 H5。Windows 现有客户端可直接使用放宽后的帐号规则，无需先更新 Windows。

## 1. 备份并停止本应用后端

备份 `account_management` 数据库以及 `/opt/acc_mgr/backend` 的原 JAR、配置和加密密钥。只停止帐号管理后端，不操作其他业务服务或 Apache。

## 2. 执行一次增量迁移

前置条件：已执行 002、003、004、005。未启用钉钉也需要 005 的绑定表。

```bash
mysql -u root -p --default-character-set=utf8mb4 account_management < 006-mobile-search.sql
```

脚本新增 `am_dingtalk_bindings.ding_name`，将帐号的 `(platform_id, login)` 唯一索引替换为普通索引。只执行一次；不要重新执行建库或历史建表脚本。

新规则：同平台、同登录帐号、同帐号名称才算重复。名称为空也参与比较；名称遵循数据库原有排序规则，登录帐号保留原有大小写比较规则。新增和修改均检查；不同名称的记录有独立密码、标签及分享授权。

为兼容 MySQL 5.5 的 767 字节索引限制，三字段判重在后端事务内完成，所有帐号写入均先锁定所有者行以串行化并发请求。不要绕过 API 直接写帐号表。旧版本后端不包含此检查，执行迁移后必须配套新 JAR。

## 3. 更新程序和页面

从 `account-management-core.zip` 取出新 `account-management.jar`，替换原 JAR，保留配置、依赖和密钥，按原方式启动本应用。

将 `account-management-mobile.zip` 中的 `index.html`、`app.js`、`styles.css` 一起覆盖到 `/opt/acc_mgr/mobile`，重新打开钉钉微应用。页面资源带新版标识以避免旧缓存。

## 4. 钉钉姓名

使用现有企业应用调用[钉钉用户详情接口](https://open.dingtalk.com/document/development/query-user-details)读取姓名。管理员需要确认应用具备读取对应人员通讯录信息的权限及可见范围。绑定或免登成功时同步姓名；已有绑定在“我的”查询绑定信息时，对空姓名自动补齐。

姓名获取失败不会阻止原有免登，也不会清除已保存姓名。“我的”会提示姓名未同步，可补好权限后点“刷新绑定信息”重试。已保存姓名在下一次钉钉登录时更新。姓名只用于展示和搜索，身份绑定仍使用企业 ID 与钉钉用户 ID。

分享查找支持完整用户名精确匹配或钉钉姓名片段匹配，仅返回启用且非本人的用户；同名用户显示各自完整用户名。姓名未经同步的用户仍可按完整用户名查找。

## 5. 上线验收

- “找帐号”切换自己的／分享给我的帐号，搜索、折叠筛选和列表复制密码可用。
- 详情“整体复制”按平台名称、地址、帐号、密码四行输出；分享给我的帐号也可复制，无再次分享入口。
- HTTP 或剪贴板受限环境显示可长按复制的文本；离开页面或切到后台清除页面中的密码文本。
- 分享页管理已发出的授权，可按姓名或完整用户名搜索、分享、撤销；H5 不提供批量分享或帐号编辑录入。
- “我的”显示完整钉钉姓名、绑定状态，改密、解绑及退出仍可用。
- Windows 同平台同登录帐号、不同名称可保存；名称也相同则提示重复；已有数据仍可解密。

本地使用 Java 8、H2 MySQL 模式验证；真实 MySQL 5.5 与钉钉权限、手机剪贴板需部署后按上述步骤验收。

回退前先检查是否已产生同平台同登录帐号的多条记录。有此类新数据时不能直接恢复旧唯一索引；应停服务并从升级前备份整体恢复数据库和旧程序（会丢失升级后新增数据），或先人工确认数据合并方案。
