# 分享给别人列表升级（Windows 1.1.3）

适用于已部署分享和标签功能的服务器。本次仅给帐号列表响应增加 `share_count`，表示已授权接收人数（包括已停用但尚未撤销授权的用户）。查询仍按帐号所有者隔离，不返回接收人身份或密码。

1. 备份现有 `/opt/acc_mgr/backend/account-management.jar`，按原运行方式停止帐号管理服务。
2. 用本次 `build/account-management.jar` 替换原 JAR，保留原配置、加密密钥和 `lib` 目录。
3. 按原方式启动帐号管理服务，验证登录和帐号列表后，再发布 Windows 1.1.3 更新包。

不执行 SQL，不重新初始化管理员，不修改另一项 Spring Boot 业务。旧客户端可继续使用新后端。回滚时可恢复备份 JAR，新客户端的新入口会提示升级后端（非空旧列表）；其余功能不受本次响应字段影响。
