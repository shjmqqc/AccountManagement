```text

character_set_results=null
PASS connection, database charset and Chinese/emoji round-trip
No tables or business data were written. Storage round-trip remains untested.
```

1. 探针程序及驱动可在服务器现有 Java 环境中运行。

5. 中文和四字节字符通过参数化 SELECT 查询往返后保持一致。

## 本机核心后端验证

2026-10-10：使用 JDK 1.8.0_192 编译，H2 2.2.224 MySQL 模式执行实际 HTTP/JDBC 测试，共通过 164 项检查。

- 登录、双会话、退出、会话过期、停用状态、强制改密、连续登录失败限制。
- 修改登录密码后所有旧会话失效，帐号数据及解密能力保留。
- 平台/帐号增删改查，重复记录、非空平台删除、所有权校验、跨用户访问拒绝。
- 四字段全局搜索、不搜索密码、普通响应不泄漏密码或密文。
- AES-GCM 加解密、随机 nonce、错误密钥/上下文/篡改拒绝、数据库不保存明文密码或会话令牌。
- 空平台密码、更新省略密码时保留、最后保存覆盖、重建服务实例后读取已有 JDBC 数据。
- 无效 JSON、请求体上限、字段长度、URL 校验及 no-store 响应。
- 服务器自检程序本身在本机 HTTP 测试环境运行成功，并清理其创建的虚构测试记录。
