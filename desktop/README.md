# Windows 帐号管理客户端（含管理功能）

技术栈：C#、.NET 10、WPF、CommunityToolkit.Mvvm 8.4.2、WPF UI 4.3.0。

## 打开程序

解压 `AccountManagement-win-x64.zip` 的全部文件到同一目录，然后双击 `AccountManagement.exe`。
发行包携带 .NET Desktop Runtime，不需要同事另外安装 .NET，也不需要管理员权限。不能只复制 EXE。

目标为 Windows 10/11 x64；本机验证环境为 Windows 11，Windows 10 具体版本尚待用户电脑实测。微软的 .NET 10 官方 Windows 10 支持范围限于其支持表列出的版本，不能保证所有旧 Windows 10 构建。

## 连接当前服务器

新版支持直接 HTTP 连接：后端配置 `http.host=0.0.0.0` 后，客户端填写 `http://服务器IP:18082`，无需 SSH 隧道。服务端安全组和防火墙需要允许该端口。0.0.0.0 不能作为客户端服务器地址；HTTP 链路不加密。

若后端仍监听 `127.0.0.1:18082`，也可继续在 Windows PowerShell 建立 SSH 隧道（替换服务器 IP 和 SSH 用户）：

```powershell
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:18082:127.0.0.1:18082 SSH用户名@服务器IP
```

SSH 身份验证按现有服务器配置完成。该终端保持开启，没有输出是正常情况；Ctrl+C 关闭隧道。此命令不开放服务器 HTTP 或 MySQL 端口，不修改现有业务。

客户端服务地址填写 `http://127.0.0.1:18082`，使用已初始化的管理员用户名、登录密码登录；不是 Linux root 或 MySQL 用户密码。
若本机 18082 已占用，可将命令第一个端口改为 28082，客户端对应填写 `http://127.0.0.1:28082`，服务器端口仍为 18082。

后续 Nginx 配置 HTTPS 并代理到后端 HTTP 后，可填写 `https://你的域名`。客户端允许 HTTP 和 HTTPS，但拒绝含用户名密码的 URL、带路径/查询参数的服务地址，不绕过 HTTPS 证书验证，也不自动跟随重定向。

## 已实现

- 登录、退出、修改登录密码；处理强制改密、会话过期。
- 三栏布局：平台、帐号、详情；可拖动栏间分隔线。
- 全局搜索（按回车或点击搜索）、平台过滤、刷新。
- 新增/编辑/删除平台及帐号；删除前确认，非空平台禁止删除。
- 密码默认隐藏，可直接复制；切换帐号或窗口失去焦点后隐藏。
- 编辑帐号时默认不改密码；勾选修改后才提交，留空即清空。
- 打开平台网址、复制登录帐号、中文错误提示及操作状态。
- 登录令牌经 Windows DPAPI 当前用户保护后保存，按服务器的 7 天有效期恢复登录。文件位于 `%LOCALAPPDATA%\AccountManagement\session.bin`。
- 邀请注册、管理员邀请管理、用户停用/恢复及重置登录密码。
- 管理员查看他人帐号库：三栏只读模式、搜索、显示/复制密码，服务端记录密码操作审计。

不会保存登录密码、离线平台帐号库或平台密码。用户主动复制的内容会进入系统剪贴板，遵循系统的剪贴板设置。
网络异常时不自动重放保存请求；若保存结果不明确，应先刷新确认。退出时若网络断开，客户端清除本机状态，但远端令牌可能保持有效直到过期。

## 管理功能使用

管理员登录后，点击主窗口右上方的“管理”。普通用户不显示此入口，服务器也会校验权限。

1. **邀请同事**：进入“邀请管理”，点击“创建邀请”，在弹窗中复制邀请码并手动发给同事。邀请码 7 天有效、只能使用一次，关闭弹窗后不能再次查看；遗失时撤销并重新创建。列表显示使用/撤销/过期状态，可刷新或加载更多。
2. **同事注册**：登录页填写可访问的服务地址，点击“使用邀请码注册”，设置用户名和至少 6 位密码。用户名注册后不可修改，注册完成后返回登录页登录。若采用 SSH 隧道方式，同事也需要有效的 SSH 连接条件；直接 HTTP/HTTPS 连接无需隧道。
3. **查看数据**：在“用户管理”选择用户，点击“查看帐号库”。顶部显示正在查看的用户名和只读提示；新增、编辑、删除入口隐藏。显示和复制密码分别记录审计，点击“返回本人数据”退出查看模式。
4. **停用/恢复**：选择普通用户后点击对应按钮并确认。停用立即撤销全部会话，数据保留；恢复后需要重新登录。
5. **重置密码**：选择普通用户并确认重置，在弹窗复制临时密码交给本人。旧会话立即失效，用户登录后必须改密。临时密码仅展示一次，遗失可再次重置；重置不会自动恢复已停用用户，也不会改动平台密码。

邀请码和临时密码不写入客户端配置或列表，只在结果弹窗显示。复制仍会进入系统剪贴板。请求超时后不要直接认定失败：先刷新邀请/用户状态；重置结果遗失时可再次重置获取新临时密码。正在提交操作时，管理和注册窗口暂不能关闭，以便展示结果。

## 更新客户端

退出旧客户端，将新 ZIP **全部解压**到一个新目录，再运行其中的 `AccountManagement.exe`。无需重装 .NET；原本的登录状态保存在用户目录，可继续使用（服务器未撤销会话时）。不要只替换 EXE。服务器须先执行 004 分享/标签增量脚本并更新后端，见 [升级说明](../backend/SHARING-UPGRADE.md)，不要重建密钥。

关闭主窗口或登录窗口会结束程序进程；“退出登录”会返回登录页。新版已修复关闭窗口后进程残留的问题。若旧版已留下后台进程，先确认没有未保存的编辑，再在任务管理器中结束旧版 AccountManagement.exe，之后使用新版本。

## 当前范围

### 分享和标签

- 在本人帐号详情点击“分享”，按完整用户名查找已启用用户，点击“添加授权”；逐个添加即可分享给多人。选中已授权用户可手动撤销。
- 接收人点击左侧“分享给我”，可查看来源、帐号、标签，显示或复制密码；不能编辑、删除或再次分享。所有者更新后点击“刷新”获取最新数据。
- 编辑帐号时点击选择多个已有标签，或输入名称并选择颜色创建标签。保存后应用到帐号，取消选中即可从该帐号移除标签。同用户同名标签复用原颜色，不影响其他帐号。
- 标签名称最多 40 字符，每帐号最多 20 个，预设蓝、绿、橙、红、紫、灰六色。目录标签暂不支持重命名或删除；取消表单仍保留新建的目录标签。
- 左侧单标签筛选与关键词搜索取交集；关键词仍搜索平台、帐号名称、登录帐号、备注，不搜索标签文字。收到的同名标签按来源区分。
- 授权无到期时间。撤销后后续请求被拒绝，已显示或复制的内容无法收回。停用所有者期间其分享暂停，授权保留；停用接收人立即撤销其会话。

已接入邀请及管理员管理接口；审计由服务器保存，尚未提供 Windows 审计查询页面。
微信小程序、自动升级、安装程序及代码签名未包含。此包用于当前阶段联调；建议先使用虚构数据。

## 开发与验证

安装 .NET 10.0.401 SDK，或使用项目 `.tools/dotnet` 下的独立 SDK。`global.json` 锁定 SDK 特性带，NuGet 锁文件记录依赖。

```powershell
# 在 desktop 目录
..\.tools\dotnet\dotnet.exe build AccountManagement/AccountManagement.csproj -c Release
.\test.ps1
.\publish.ps1
```

测试脚本先编译真实 Java 后端与隔离 H2 测试库，在本机 18083 端口启动一次性服务，执行客户端接口/视图模型验证并生成离屏界面预览，最后停止自己创建的服务。
仅用虚构测试帐号，不连接生产服务器、不修改系统剪贴板；需要事先运行 `backend/build.ps1` 准备 Java 依赖。测试数据目录为 `desktop/artifacts`，不提交 Git。

源码目录：Models 为接口数据，Services 为通信及登录状态，ViewModels 为列表和密码显示状态，Views 为界面及窗口交互。没有引入模块化框架或离线数据库。

已知验证边界：本机 H2 联调不替代服务器 MySQL 全流程、真实 SSH/HTTPS 接入或 Windows 10 实机测试。
