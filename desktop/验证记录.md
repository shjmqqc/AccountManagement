## 本机验证

`test.ps1` 在本机启动真实 Java 核心后端代码，数据存入一次性 H2 内存数据库，测试后仅停止该脚本创建的进程。

共 43 项检查通过，覆盖：

- HTTP 服务地址限制、HTTPS 地址接受、拒绝公网明文 HTTP 及带凭据/路径的地址。
- 登录、身份读取、恢复有效会话、失效会话清理界面、改密后旧会话失效。
- Windows DPAPI 登录状态读写、磁盘不含明文令牌、过期和损坏文件处理。
- 平台与帐号增删改查、全局搜索、重复平台拒绝、非空平台拒删、跨用户访问拒绝。
- 编辑省略密码时保留原值、显式空字符串清空、修改登录密码后仍能解密原平台密码。
- 密码显示、切换记录后隐藏、隐藏状态复制、迟到的密码响应被丢弃。
- 异步操作结束后命令及实际搜索按钮重新可用。
- 登录页、三栏主界面（1320×820 和 1060×660）、帐号编辑、平台编辑和改密窗口的离屏布局渲染。

已目视检查生成的预览。测试使用虚构信息；复制测试验证传入剪贴板操作的内容，不修改使用者当前系统剪贴板。
